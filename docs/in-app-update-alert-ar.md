# تنبيه تحديث تطبيق جمعية التعاون الخيرية

يظهر التنبيه داخل التطبيق عند تشغيله أو الرجوع إليه بعد نشر إصدار أحدث، مع زر «تحديث الآن» الذي يفتح صفحة **Google Play** الصحيحة، وزر «لاحقًا» (ما لم يحدد المسؤول أن التحديث إلزامي). ويمكن التحقق يدويًا من صفحة الإعدادات.

## التثبيت على WordPress

1. نزّل ZIP الخاص بإضافة `altaawun-app-updates-wordpress` من قسم **Actions → Package Altaawun Update Plugin → Artifacts**.
2. في لوحة WordPress لموقع `aytamaliraq.com`: **الإضافات → أضف إضافة جديدة → رفع إضافة**، ثم فعّلها.
3. افتح **الإعدادات → تحديثات تطبيق الجمعية**.
4. لكل مسار (Android Alpha، Android Production، iPhone): ضع `version` و`build` **فقط بعد** نشر هذا الإصدار للمختبرين/المستخدمين المعنيين.
5. افتح `https://www.aytamaliraq.com/wp-json/altaawun-app/v1/update?platform=android&channel=alpha` للتأكد من أن الرد يحمل رقم البناء الصحيح و`enabled:true`.

## مثال

إذا ثبّت المستخدم نسخة Android ببناء 217، ونشرت في Closed Testing Alpha بناء 218، حدّد Android Alpha → 1.0.2 / 218 وفعّل الإعلان. عند فتح التطبيق، تظهر النافذة. إذا كان المستخدم على 218 بالفعل فلن تظهر.

## ملاحظات مهمة

- بناء 216 الذي نُشر سابقًا لا يتضمن هذه الميزة. لن يظهر التنبيه فيه إلا بعد تحديث التطبيق إلى بناء يدعم فحص التحديثات.
- التحديث في قناة Alpha يحتاج موافقة الحساب للاختبار (tester opt-in). الرابط يفتح Google Play، ولا ينزّل APK من مصدر خارجي.
- لا يمكن تحديث نسخة APK موقعة بشهادة مختلفة فوق نسخة Google Play دون حل اختلاف التوقيع؛ رسالة التحديث لا تعالج هذه المشكلة بحد ذاتها.
- الخادم يحتفظ بآخر رقم بناء أُعلن عنه لكل مسار، ولا يستنتج نشر الإصدار من نجاح بناء GitHub Actions.
- `--dart-define=ALTAAWUN_UPDATE_CHANNEL=alpha` يتم تمريره في سير بناء أندرويد للاختبار. يجب ضبط `production` للبناء المخصص للنشر العام لاحقًا.
- مع إصدار Flutter/Android الجديد سيظهر الإصدار ورقم البناء وBy Saheb Altaai في صفحة إعدادات التطبيق.
